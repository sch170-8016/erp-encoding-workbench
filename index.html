    ERP 13位图号品名规格材料牌号路径(零/一/二/三/四/五)操作
    
    
    
    
    本表是「现存编码」统一总表 = 源表(data.js) ∪ ③编码台账（本机生成）合并去重，每行左侧徽标标出来源（源表 / 台账）。点编码右侧「复制」可复制 13 位码；点「修订」可改图号 / 品名 / 规格 / 材料牌号（13 位码本身不可改 —— 它是物料主键；确需换码请在 ① 新建）。材料牌号：源表行多为空（旧 data.js 本身无材料字段），台账行显示生成时记录的材料牌号；在此修订台账行的材料牌号会写回 ③ 台账存储。源表类修订写入修订层、台账类写入台账存储，均不改动 data.js 源文件，可随时「全部恢复」或用「导出修订清单」回写源表。「导出现存编码(CSV)」导出本页全部合并总表（含源表+台账、含当前所有列：ERP/图号/品名/规格/材料牌号/路径/来源），与「导出修订清单」互不影响。
    
  
    

  
    
    
    ⑥ 分类管理（六级品类表，逐级独立增减）
    
    
    零级=客户（01 富耐连、02 中天科技…）、一级=物料分类、二级=材料类型、三级=材料分类、四级=来源（0 自制件/1 采购件）、五级=流水（4位）。一~四级均为独立清单：二级不挂一级下、三级不挂二级下，各级单独增减。五级表每行=某「一+二+三+四」分支下一条流水码。改动自动保存本地，可导出备份 / 导入 / 从源表重置。
    
    
    
    
    
      
      
      
      
      
      
      
      
      
    
    
    
    
      
    
    
    
    
    
    CSV 列：层级,零级码,零级名称,一级码,一级名称,二级码,二级名称,三级码,三级名称,四级码,四级名称,差异维度,说明（可用 Excel 直接打开编辑）。「层级」填 零级/一级/二级/三级/四级，每级一张独立清单——每行只填本级的码和名称（上级列留空即可），二级不挂一级、三级不挂二级，不会产生重复组合。导入按「码」匹配：已存在则更新名称/差异维度/说明，不存在则新建，默认不删除。五级流水不进 CSV，导入后原样保留。
    

    
    
      
    零级：下拉选客户 → 旁边「改名 / 删除」。一~四级：下拉列出该级全部条目 → 旁边「改名 / 删除」（四级来源为全局共用枚举，只列 0 自制件 / 1 采购件）。五级：按「一+二+三+四」分支折叠，每行一条流水，可就地改码/改名/填说明，或「按自动流水补下一行」。
